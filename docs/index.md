# ConnectedVan Ecosystem

Welcome to the central documentation hub for the ConnectedVan project. Here you will find production-ready hardware layouts, pinouts, and firmware flashing utilities for your modular campervan automation boards.

## Active Projects
* **Autoterm Controller:** Galvanically isolated ESP32 interface for diesel heaters.
* **400A Shunt BMS:** High-amperage isolated current and voltage monitor (Development phase).
