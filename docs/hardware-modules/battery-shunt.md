# Battery Shunt Module

The ConnectedVan Battery Shunt is a high-precision, isolated current and voltage monitor built around the ESP32-C6. It is designed to replace proprietary battery monitors and feed your power data directly into Home Assistant.

:::danger High Amperage Safety
This module is designed to sit inline with your main house battery bank. Always disconnect your main battery terminals and solar arrays before installing or servicing the shunt.
:::

## Technical Specifications

| Feature | Specification |
| :--- | :--- |
| **Microcontroller** | ESP32-C6 (Wi-Fi 6 & Bluetooth LE) |
| **Current Capacity** | Designed for 400A+ brass shunts |
| **Voltage Range** | 12V / 24V / 48V System Compatible |
| **Isolation** | Galvanically isolated measurement circuit |
| **Integration** | Native ESPHome / Home Assistant |
