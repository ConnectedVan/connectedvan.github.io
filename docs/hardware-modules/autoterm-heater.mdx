# Autoterm Heater Module

The ConnectedVan Autoterm Heater module is a custom ESP32-C6 interface designed to communicate directly with Autoterm diesel heaters via their proprietary serial protocol. 

:::danger High Voltage Isolation
Always ensure the 12V/24V heater power lines are completely physically isolated from the 3.3V ESP32 logic side. The PCB utilizes galvanic isolation to protect the microcontroller from voltage spikes during heater ignition.
:::

## Technical Specifications

| Component | Specification |
| :--- | :--- |
| **Microcontroller** | ESP32-C6 (Wi-Fi 6 & Bluetooth LE) |
| **Operating Voltage** | 12V DC (Vehicle System) |
| **Logic Level** | 3.3V |
| **Isolation** | ADuM1201 or similar digital isolator |
| **Communication** | UART (Reverse-engineered Autoterm protocol) |
